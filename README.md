# 黏菌圖鑑 · Slime Atlas

[開始試玩 / Play](https://tongji-mit-csl-sh.github.io/slime-atlas/)

V0.11 · 繁體中文 · 五章十五關 · 教師與學生試玩版

從觀察黏菌的局部感知、共享連接與備用路徑，走到虛構小鎮的居民服務與方案取捨。完成關卡後可收集一張發現卡、點亮章節，最後用實測記錄支持自己的提案。

## 給第一次試玩的老師

1. 由「探索地圖」進入 001「初見」，依次體驗第一章。
2. 想快速看城市部分，可由地圖選 011「到達」、012「看見」。
3. 013–015 共用方案與測試記錄，建議按順序體驗。
4. 「我的圖鑑」可查看卡片；只有實際完成關卡才能收藏。

不需要登入或付費 API。電腦與手機瀏覽器皆可開啟；橫豎屏與觸控仍歡迎實機反饋。遊戲進度只存於當前瀏覽器，不會跨裝置同步；請勿在共議留言中填寫個人敏感資訊。清除網站資料或使用私密瀏覽可能失去進度。001／002 尚未收卡的現場試驗不跨刷新保存。

插畫是 AI 輔助製作並經人工檢視的概念圖，不是顯微照片或測量地圖。人物與城鎮均為虛構教學設定，互動結果來自明示的教學模型，不代表真實城市的規劃建議。這是可試玩的教育原型，尚未經真人學生學習成效驗證；英文教學版本仍待完善。

## Repository scope

This repository contains only the allowlisted static game runtime, its shared growth engine, optimized illustrations and release metadata. It does **not** contain the private research repository, manuscripts, research datasets, artwork masters, credentials or development history.

The game runs entirely in the browser, with no game-side analytics, account service or runtime AI calls. GitHub Pages provides hosting. The original research repository remains private.
